Watching a room, catching the collapse

One full run of the wisp detector on the synthetic demo room — the exact same pipeline (clean → features → anomaly model → temporal state machine) that will run on live ESP32 data. Below is what the detector actually saw, and where it fired.

Motion intensity — the workhorse signal

Cross-subcarrier amplitude variance per ~1 s window. High while someone moves, near-zero when the room goes still. A collapse is a drop into stillness that persists.

Transient sharpness — the impact detector

Largest single-step amplitude change per window. It spikes when a body hits the floor (a sudden collapse) and stays quiet for a gradual slump (a slow collapse).

Confirmed alerts

What the one-line console prints — one row per confirmed collapse, after the pattern (disturbance → stillness ≥ T) is satisfied.
